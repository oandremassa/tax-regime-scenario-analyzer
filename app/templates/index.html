ABOUT THE PROJECT

Why this exists

This repository is an anonymized portfolio rebuild inspired by a real process-improvement challenge in an accounting workflow. The original problem involved scattered financial inputs, manual comparisons and limited traceability between source data and management decisions.

The public version uses only fictional companies and synthetic figures. The tax formulas are deliberately simplified: the project demonstrates software design, data organization, validation, auditability and decision-support logic rather than tax compliance.
