# Data model

## companies
Stores the synthetic company master data used to organize scenarios.

Key fields: `company_code`, `legal_name`, `sector`, `city`, `state`, `current_regime`.

## analyses
Stores one set of annual assumptions for a company.

Key fields: `annual_revenue`, `payroll`, `operating_costs`, `service_share`, `commerce_share`.

## simulations
Stores the JSON output generated by the scenario engine. This preserves the engine version used for each run.

## imports
Stores metadata about imported CSV files and the annual totals derived from them. The demo does not persist the source CSV contents.
